# PocketLLM

> **Minimal. Fast. Instant answers.**

---

## About the Project

**PocketLLM** is a lightweight desktop widget for quick interactions with a language model.  
Forget long chats and endless message histories. With **PocketLLM**, every question gets a fast, concise answer — no noise, no extra clicks.

The main goal of the project is to make working with an AI model **instant and convenient**, right from your desktop. Press a hotkey, ask a question, get the answer — done.

---

## Why it's Awesome

- **Minimalism**  
  Just a small window, no unnecessary buttons or complicated settings. Only input and output.

- **Speed**  
  Opens instantly with a hotkey, provides quick answers, and collapses back to the system tray.

- **Lightweight**  
  Minimal system requirements; barely uses memory or CPU.

- **Always Within Reach**  
  Lives in the system tray and ready whenever you need it — like a calculator, but for AI.

- **Customizable UX**  
  Auto-close window and dark theme — designed for your convenience.

---

# How install
1. Download the latest release from the [GitHub repository](https://github.com/Elikaka2/PocketLLM)
2. Extract the downloaded file to a desired location on your computer.
3. Run the `PocketLLM.exe` file to start the application.
4. Configure your API key and preferences in the settings menu.
5. (Optional) Add to auto-start for quick access on system startup.
